Xolo¶

Xolo est une passerelle LLM souveraine pour l'entreprise. Elle permet de contrôler, surveiller et sécuriser l'accès aux modèles de langage au sein de votre organisation.

Cette documentation est générée à partir des sources Markdown versionnées dans xolo-gateway/xolo. Chaque publication correspond à un tag sémantique du projet principal.
