Politique de marque¶

Traduction française de TRADEMARK.md ; la version anglaise fait foi.

L'AGPL-3.0 donne à chacun le droit d'utiliser, de modifier et de redistribuer le logiciel. Elle ne donne à personne le droit d'utiliser le nom et le logo du projet d'une manière qui laisse croire que son travail est la version officielle. Cette politique trace cette ligne, pour qu'un utilisateur qui voit « Xolo » sache ce qu'il obtient.

Les marques¶

La marque verbale Xolo et le logo Xolo (les fichiers sous internal/http/handler/webui/common/assets/ : logo.svg, banner.svg, favicon.svg et leurs variantes bitmap) sont déposés en France auprès de l'INPI, sous les numéros 5295297 pour la marque verbale et 5295272 pour le logo. Ils sont détenus par William Petit, mainteneur principal, jusqu'à la création d'une association destinée à porter le projet, à laquelle les marques seront alors cédées. Cette politique sera mise à jour ce jour-là ; les permissions ci-dessous seront reprises telles quelles.

Ce que vous pouvez faire sans demander¶

  • Désigner le projet. « Construit sur Xolo », « compatible avec Xolo », « un plugin pour Xolo », « instance Xolo hébergée », « conseil Xolo » : nommer le logiciel avec lequel vous travaillez est un usage descriptif, toujours autorisé.
  • Redistribuer les versions officielles sans modification, sous le nom Xolo, y compris via un paquet ou une image de conteneur, à condition d'indiquer de quelle version officielle il s'agit.
  • Héberger une version officielle non modifiée pour vos utilisateurs et l'appeler Xolo.
  • Écrire des plugins et les présenter comme des plugins Xolo, sous n'importe quelle licence (voir LICENSE-EXCEPTION). Un plugin peut porter « Xolo » dans son nom en position descriptive, par exemple xolo-plugin-ldap ou « Synchronisation LDAP pour Xolo ».
  • Utiliser le logo pour renvoyer vers le projet ou illustrer une conférence, un article ou un cours sur Xolo, sans altération et sans suggérer un soutien du projet.
  • Forker le code, conserver le nom du dépôt si c'est ainsi que fonctionne votre plateforme d'hébergement, et indiquer qu'il s'agit d'un fork de Xolo.

Ce qui requiert une autorisation¶

  • Distribuer une version modifiée sous le nom Xolo. Un fork qui modifie le code, ou un build avec des correctifs non officiels, doit être diffusé sous un autre nom, ou sous un nom qui rend la différence évidente, comme « le fork de Xolo par Acme ». Un changement de configuration, un thème ou un plugin ne rendent pas une version « modifiée » au sens de cette politique ; un patch du cœur, si.
  • Nommer un produit, un service, une société ou un nom de domaine avec « Xolo » d'une manière qui pourrait être prise pour le projet lui-même ou une offre officielle : « Xolo Cloud », « Xolo Enterprise », xolo-gateway.example.
  • Suggérer un soutien ou une affiliation : « officiel », « certifié », « partenaire », ou le logo sur une page qui vend un service, sauf si le projet l'a dit.
  • Altérer le logo : changer ses couleurs, ses proportions ou ses éléments, le combiner avec une autre marque.

Demandez en ouvrant une issue ou en écrivant à l'adresse indiquée dans MAINTAINERS.md. Les demandes publiques reçoivent une réponse publique. L'autorisation, lorsqu'elle est accordée, est non exclusive et peut être retirée si les conditions dans lesquelles elle a été donnée ne sont plus réunies.

Déclarations de compatibilité¶

Vous pouvez dire que votre logiciel fonctionne avec Xolo, ou avec une version donnée de Xolo, lorsque c'est le cas. Indiquez la version, et ne présentez pas une déclaration de compatibilité comme une certification du projet.

Signaler un usage abusif¶

Si vous voyez le nom ou le logo utilisés d'une manière qui trompe les utilisateurs sur ce qui est officiel, signalez-le via le contact indiqué dans MAINTAINERS.md.

Évolution de cette politique¶

Cette politique peut être assouplie à tout moment. La rendre plus stricte suit le processus de RFC de GOVERNANCE.md, avec la période de commentaires de trente jours, et ne s'applique jamais rétroactivement aux usages autorisés au moment où ils ont commencé.
